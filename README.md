# ケアレポAI（法人専用版）

介護現場の報告文をAIで添削し、「家族向け報告」と「社内向け報告」に整理する介護施設・法人向けWebアプリです。写真からの文字読み取り、介護用語辞書、履歴保存、企業コード登録、契約人数管理、1日5回の利用制限に対応しています。

## 法人料金

| プラン | アカウント数 | 1アカウント単価 | 月額・税込 |
| --- | ---: | ---: | ---: |
| スターター | 10まで | 550円 | 5,500円 |
| スタンダード | 30まで | 500円 | 15,000円 |
| ビジネス | 50まで | 450円 | 22,500円 |
| エンタープライズ | 51以上 | 個別設定 | 個別見積もり |

- 法人契約・銀行振込
- 入金確認後にアウトイン管理画面から契約を有効化
- 職員の個人決済なし
- 企業コードを持たない一般ユーザーは登録不可
- AI添削は1アカウントにつき1日5回（日本時間0:00にリセット）

## 主な機能

- メールアドレス・パスワード認証
- 企業コード必須登録
- 契約人数上限のサーバー側トランザクション判定
- 報告書画像のOCR
- 家族向け／社内向け文章の生成
- `KOT`、`BT`、`BP`、`HR`、`SpO2`、`Ns`、`Dr`、`食介` 等の介護用語判定
- 社内向け文章では入力された氏名を維持
- Firestoreへの履歴保存
- サーバー側による1日5回制限
- アウトイン側の企業契約管理
- 企業管理者向け利用状況・CSV出力
- 特商法、利用規約、プライバシーポリシー、返金方針、お問い合わせ
- PWA／ホーム画面アイコン

## セットアップ

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

`.env.local.example` を参考に、OpenAI、Firebaseクライアント、Firebase Adminを設定してください。

Firebase Adminの秘密鍵は、Vercelでは改行を `\n` に置き換えた1行の環境変数として登録できます。

`ADMIN_EMAILS` には、アウトイン側の企業契約管理画面を利用するメールアドレスをカンマ区切りで設定します。既存ユーザーでも、設定したメールアドレスでログインしてマイページを開くと管理者権限が反映されます。

## Firebase

1. Authenticationでメール／パスワードを有効化
2. Firestore Databaseを作成
3. 同梱の `firestore.rules` をデプロイ
4. Firebase Admin用サービスアカウント情報を環境変数へ登録

企業契約情報、権限、利用回数はクライアントから変更できないルールです。

## 企業導入の流れ

1. 施設と契約プラン・期間を決定
2. 請求書を発行
3. 銀行振込を確認
4. `/admin/companies` で企業名・プラン・期間・企業管理者メールを登録
5. ステータスを「利用中」に変更
6. 発行した企業コードを施設へ案内
7. 職員が企業コードを使って会員登録
8. 企業管理者が `/company` で利用状況を確認

## 公開前チェック

```bash
npm run build
```

- アウトイン管理者による企業登録
- 10・30・50アカウントプランの料金・上限
- 入金待ち状態では企業コード登録できないこと
- 利用中へ変更後に企業コード登録できること
- 企業コードなしでは一般ユーザー登録できないこと
- 契約人数を超える登録が拒否されること
- 企業管理者が所属職員のみ確認できること
- 1日5回利用後に6回目が拒否されること
- 翌日0:00（日本時間）以降に回数が戻ること
- 履歴保存と削除
- CSV出力
- iPhone／iPadのホーム画面アイコン
